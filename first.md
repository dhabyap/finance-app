# OpenCode Guide

Welcome to OpenCode! This is your first time using OpenCode, an open source AI coding agent.

## What can you do with OpenCode?

### 1. Code Editing & Writing
- Ask OpenCode to write code for you (functions, classes, entire files)
- Get help fixing bugs in your code
- Refactor and improve existing code

### 2. Explore Your Codebase
- Search for files, functions, classes across your project
- Understand how different parts of your code work
- Answer questions about your codebase

### 3. Run Commands
- Execute terminal commands (git, npm, docker, etc.)
- Run tests and builds
- Install dependencies

### 4. Search the Web
- Look up documentation
- Find examples and best practices
- Get help with APIs and libraries

### 5. Multi-file Operations
- Edit multiple files at once
- Create new files and directories
- Restructure your project

## Getting Started

Just tell OpenCode what you need! Examples:
- "write a function to calculate Fibonacci numbers"
- "find where the login logic is in this codebase"
- "fix the bug in src/api.js on line 42"
- "explain what this code does"

## Tips

- Be specific about what you want
- Tell OpenCode which files to work on
- Ask for clarification if needed
- Use /help for more commands
